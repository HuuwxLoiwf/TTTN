  ProjectMessage        .project          -> Project                 fk=projectId      ref=id     onDelete=Cascade  
  ProjectMessage        .user             -> User                    fk=userId         ref=id     onDelete=Cascade  
  ProjectMember         .user             -> User                    fk=userId         ref=id     onDelete=Cascade

  Task                  .project          -> Project                 fk=projectId      ref=id     onDelete=Cascade

  TaskDependency        .task             -> Task                    fk=taskId         ref=id     onDelete=Cascade  rel:DependentTask
  TaskDependency        .dependsOn        -> Task                    fk=dependsOnId    ref=id     onDelete=Cascade  rel:BlockingTask
  Subtask               .task             -> Task                    fk=taskId         ref=id     onDelete=Cascade  
  TimeLog               .task             -> Task                    fk=taskId         ref=id     onDelete=Cascade  
  TimeLog               .user             -> User                    fk=userId         ref=id     onDelete=Cascade  
  Comment               .user             -> User                    fk=userId         ref=id     onDelete=Cascade  
  Comment               .task             -> Task                    fk=taskId         ref=id     onDelete=Cascade  
  Activity              .user             -> User                    fk=userId         ref=id     onDelete=Cascade

  AuditLog              .user             -> User                    fk=userId         ref=id     onDelete=Cascade  
  AuditLog              .workspace        -> Workspace               fk=workspaceId    ref=id     onDelete=Cascade  
  Notification          .user             -> User                    fk=userId         ref=id     onDelete=Cascade  
  File                  .project          -> Project                 fk=projectId      ref=id     onDelete=Cascade  
  File                  .task             -> Task                    fk=taskId         ref=id     onDelete=Cascade

=== UNIQUE / INDEX ===
  User                   email         String    @unique
  Workspace              slug        String   @unique
  Department             @@unique([workspaceId, name]) // tên phòng ban không trùng trong cùng workspace
  WorkspaceMember        @@unique([userId, workspaceId]) // prevent duplicate membership
  ProjectMemberRequest   @@unique([projectId, userId, status])
  ProjectMember          @@unique([userId, projectId]) // prevent duplicate membership
  TaskDependency         @@unique([taskId, dependsOnId])
  AuditLog               @@index([workspaceId, createdAt])
  Equipment              @@unique([workspaceId, code]) // mã thiết bị không trùng trong cùng workspace
